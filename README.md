# МедиаКоми 🏠

Игра-угадайка по данным реальных объявлений о продаже квартир в Республике Коми (Инта).
Игроку показывают фотографии квартиры, он называет цену бегунком — и узнаёт реальную цену,
свою ошибку и баллы. 10 квартир за раунд, в конце — вердикт: «Жадный студент»,
«Адекватный квартирант» или «Транжира».

## Как опубликовать на GitHub Pages (5 минут)

1. Создайте новый репозиторий на GitHub (например, `mediakomi`).
2. Загрузите в него файлы `index.html` и `data.js` (и этот README):

   ```bash
   git init
   git add .
   git commit -m "МедиаКоми: игра угадай цену квартиры"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_НИК>/mediakomi.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. Через 1–2 минуты игра будет доступна по адресу
   `https://<ВАШ_НИК>.github.io/mediakomi/`.

Сборка не нужна — это чистые HTML/JS без зависимостей.

## Как обновить данные

Данные лежат в `data.js` в виде массива `window.LISTINGS`:
`{ url, photos[], price, desc, street }`. Достаточно дописать новые объявления
(скрипт игры сам выбирает 10 случайных активных лотов с фото из списка).

## Устройство игры

| Экран | Что происходит |
|---|---|
| Стартовый | Название, короткие правила, кнопка «Запустить игру» |
| Лот | Галерея фото (свайп) + описание, бегунок цены, кнопка «Оценить» |
| После оценки | Реальная цена, ваша оценка, разница в ₽ и %, баллы, ссылка на объявление |
| Итог | Сумма баллов, вердикт по среднему отклонению оценок, список всех раундов |

### Балльная система (максимум 100)

Относительная ошибка `|ваша цена − реальная| / реальная`:

| Ошибка | Баллы |
|---|---|
| ≤ 5 % | 10 |
| ≤ 10 % | 8 |
| ≤ 20 % | 6 |
| ≤ 35 % | 4 |
| ≤ 50 % | 2 |
| > 50 % | 0 |

### Вердикты

Считается среднее смещение оценок `(ваша цена − реальная) / реальная` по 10 раундам:

- **Жадный студент** — в среднем занижали на 15 % и больше;
- **Адекватный квартирант** — отклонение в пределах ±15 %;
- **Транжира** — в среднем завышали на 15 % и больше.

## Технические решения

- **Мобильный приоритет**: одна карточка на экран, `max-width: 480px`, safe-area для «чёлок», крупный бегунок.
- **Оптимизация картинок**: первое фото — eager, остальные — `loading="lazy"` (грузятся только при свайпе), галерея на scroll-snap без JS-анимаций, картинки уже отдаются CDN Avito в сжатом виде.
- **Стиль**: фирменный тёмно-синий ВШЭ `#012D6E` + акцентный красный для кнопок.
- Нет бэкенда, cookies и аналитики — статика, подходит для GitHub Pages.
